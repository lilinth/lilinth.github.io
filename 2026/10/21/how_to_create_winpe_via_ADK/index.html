使用 Windows ADK 构建 WinPE 并部署到 WDS/PXE

适用场景： Windows Server 2025 WDS、现有 PXE 环境、服务器硬件测试与维护、命令行优先、集成网卡驱动。

1. 下载并安装工具

官方下载：Windows ADK 和 WinPE Add-on 官方下载页面

安装顺序：

  1. 安装 Windows ADK，至少选择 Deployment Tools。
  2. 安装匹配版本的 Windows PE Add-on。
  3. 打开 Deployment and Imaging Tools Environment，以管理员身份执行后续命令。

注意：ADK 与 WinPE Add-on 应使用匹配版本。Windows Server 2025 的 WDS 不支持将 Windows 安装介质的 boot.wim 作为 Windows Setup 启动映像，因此使用 ADK 创建自定义 WinPE。

诊断工具 测试程序可以正常执行

如果启动后没有获得 IP 地址，优先检查网卡驱动、链路状态、VLAN、DHCP Relay 和 DHCP 服务可达性。

9. 故障排查与回退

  • WDS 导入失败： 确认使用的是 ADK copype 生成的 WIM，而不是从 Windows ISO 提取并修改的 WIM；保留完整错误信息进一步排查。
  • 驱动注入失败： 检查 INF 文件、驱动架构和系统版本兼容性。
  • PXE 能启动但没有网络： 检查驱动是否正常加载、网卡链路和 DHCP 环境。
  • 需要恢复干净映像： 使用新的目录重新执行 copype amd64。
  • 替换现有映像前： 保留原 WIM 和现有 WDS 启动项，先在一台服务器上验证。
